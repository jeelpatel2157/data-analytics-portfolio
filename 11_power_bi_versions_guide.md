# Power BI Dashboard Versions

## Version 1: Original (Full Data)
**File:** Sales_Dashboard_Original.pbix
**Status:** Complete dataset
**View:** All regions, all months
**Total Sales:** 304,500
**Use Case:** Full analysis, presentations, reports

### Contains:
- Column Chart: All months
- Pie Chart: All regions
- Region Slicer: Functional
- All data visible

## Version 2: Custom (Filtered Example)
**File:** Sales_Dashboard_Custom.pbix
**Status:** Pre-filtered example
**View:** Demonstrates slicer functionality
**Example:** West region selected
**Use Case:** Training, demonstrations, examples

### Contains:
- Same charts as original
- Slicer showing filtering
- Example of interactive features
- Shows how end-users interact

---

## How to Use

### Original Version
1. Open Sales_Dashboard_Original.pbix
2. Explore full dataset
3. Click slicers to filter
4. Analyze trends
5. Export for presentations

### Custom Version
1. Shows filtered state example
2. Click different regions
3. Watch all charts update
4. See interactivity demo
5. Learn slicer functionality
